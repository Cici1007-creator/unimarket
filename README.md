# UniMarket

Prototipo web para que estudiantes puedan publicar y encontrar productos y servicios disponibles en el campus.

## Ejecutar el proyecto

1. Abre esta carpeta en Visual Studio Code.
2. Instala la extensión **Live Server**.
3. Abre `index.html` y selecciona **Open with Live Server**.

También puedes abrir `index.html` directamente en un navegador, aunque Live Server facilita actualizar los cambios.

## Estado actual

La aplicación funciona completamente en el navegador. Los datos se guardan en `localStorage`, por lo que todavía no hay cuentas, catálogo ni imágenes compartidos entre personas o dispositivos.
